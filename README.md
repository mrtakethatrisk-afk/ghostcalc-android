# GhostCalc for Android

The official Android app for GhostCalc. Use it to pair with your GhostCalc calculator over Bluetooth, set up Wi-Fi and AI keys, send notes, and install firmware updates.

GhostCalc isn't on the Google Play Store yet, so for now you install it straight from this page (this is called "sideloading").

### [⬇ Download the latest GhostCalc app (APK)](https://github.com/mrtakethatrisk-afk/ghostcalc-android/releases/latest/download/GhostCalc.apk)

Requires Android 7.0 or newer with Bluetooth. [All versions and release notes →](https://github.com/mrtakethatrisk-afk/ghostcalc-android/releases)

## How to install

1. **On your Android phone**, open this page in Chrome and tap the download link above.
2. When the download finishes, tap **Open**. You can also find `GhostCalc.apk` in the **Files** app under **Downloads**.
3. If Android says it can't install apps from this source, tap **Settings**, turn on **Allow from this source**, then go back.
4. Tap **Install**.
5. If Google Play Protect shows a message, you can let it scan the app. If it warns you about an unknown app, tap **More details** and then **Install anyway**. Play Protect shows this for any app that doesn't come from the Play Store.
6. Open GhostCalc. When it asks for **Nearby devices** (Bluetooth), tap **Allow** so it can find your calculator.

## How to update

Download the APK again from the same link and install it over the one you have. Your app settings are kept. The **Update** tab inside the app is only for your calculator's firmware, not for the app itself.

## Troubleshooting

**"App not installed" or "package conflicts with an existing package"**
You have a copy of GhostCalc from somewhere else, like an older test build. Uninstall that copy, then install this one.
Uninstalling deletes the app's data on your phone, including your PIN and saved settings. Make a backup in the app's **Settings** first if you can.

**The app can't find my calculator**
- Make sure Bluetooth is on.
- Go to **Settings → Apps → GhostCalc → Permissions** and allow **Nearby devices**. On Android 11 and older, allow **Location** instead.
- Keep the calculator close to your phone and make sure it's awake.

**I can't install apps from outside the Play Store**
Some work or school phones block this. You can still set up your GhostCalc in Chrome at [ghostcalc.org/connect](https://ghostcalc.org/connect).

## Is it safe?

This is the official GhostCalc app, published by GhostCalc and signed with GhostCalc's release key. Android won't let an update install unless it has the same signature as the app you already have. Each release lists the file's SHA-256 checksum if you want to check your download.
